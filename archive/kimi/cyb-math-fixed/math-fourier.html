使用帮助

这是什么

任意闭合路径都可以分解为一串旋转圆环（傅里叶级数）：每个圆环对应一个频率 n 的系数 cₙ，把 N 个圆环首尾相接，末端笔尖随时间走出原路径的 N 项部分和逼近。

模式 A · 任意路径 2D

  • 手绘：点击「手绘输入」后在画布上按住拖动，松手自动完成采样与分解。
  • 预设：圆、椭圆、正方形、心形线、五角星、李萨如 3:2 / 5:4、双纽线 ∞，一键加载。
  • SVG 路径：粘贴 d 字符串（支持 M/L/H/V/C/S/Q/T/Z），解析失败会给出中文原因。
  • 项数 N：拖动滑杆实时增减参与求和的系数个数（按幅值从大到小选取），观察部分和逼近过程；右侧频谱图按频率展示 |cₙ|。

模式 B · 经典波形 1D

  • 方波 / 锯齿波 / 三角波 / 半波整流正弦；左侧旋转圆环、右侧随时间轴展开的波形，虚线实时联动。
  • 吉布斯现象：方波与锯齿波在间断点附近有约 8.95%（跳变量）的过冲；用 1×/4×/16× 观察窗放大查看，窗口同时标注理论峰值与当前 N 项实测过冲。
  • 原波形与 N 项部分和叠加显示，并给出 RMS 误差。

通用

  • 播放/暂停、速度 0.1×~4×、时间轴拖动；显示开关可分别控制圆环、矢量、轨迹线、中心点、原始轮廓。
  • 导出：当前帧 PNG、当前构图静态 SVG、WebM 录像（开始/停止按钮；浏览器不支持时会提示）。
  • 分享链接：把当前模式、路径数据与设置压缩编码进网址，打开链接即可还原。

快捷键

  • 空格 播放 / 暂停
  • ← / → 时间轴微调
  • ↑ / ↓ 项数 N ±1
  • H 打开 / 关闭帮助
  • D 切换浅色 / 深色
  • Esc 关闭帮助

数学说明

对路径按弧长等距采样 M 个点（M 取 2 的幂），用基-2 FFT 计算 cₙ = (1/M)Σ zₖ·e^(−2πi·k·n/M)；动画中 t ∈ [0,1)，圆环链末端为部分和 Σ cₙ·e^(2πi·n·t)。N 取满全部系数时可在采样点上精确还原路径。
