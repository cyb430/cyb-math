数论工具箱 · 使用说明

总览

本工具箱覆盖初等数论常用计算，全部基于 BigInt 精确整数运算，不会出现浮点误差。计算完全在浏览器本地完成。顶部可切换深浅色主题；🔗 分享会把当前工具与全部输入编码进链接，发送给他人打开即可原样还原。

各工具用法

质数工具输入 n：「质数判断」用 Miller-Rabin 素性测试（< 2⁶⁴ 为确定性结果，更大则为高概率）；「质因数分解」用试除 + Pollard-Rho（建议 ≤ 24 位）；「所有因数」列出全部正因数（超过 2000 个时不予枚举）；「相邻素数」给出 n 两侧最近的素数；「完整分析」一次输出以上全部及 φ(n)、因数个数 τ(n)、因数和 σ(n)。
素数表埃氏筛生成 ≤ N 的素数（N ≤ 5×10⁶）；π(N) 只给个数；「第 k 个素数」用 Rosser 上界先定界再筛（k ≤ 10⁵）。列表过长时仅显示前 500 个，「复制」始终复制完整内容。
素数分布绘制 π(x) 与近似 x/ln x 对比曲线（N ≤ 2×10⁶）；孪生素数对统计与列举（N ≤ 5×10⁶）；哥德巴赫拆分：任意 ≤ 40 位偶数给出一组 p+q 拆分，N ≤ 10⁶ 时枚举全部拆分。
梅森素数Lucas-Lehmer 测试精确判定 M_p = 2^p − 1（指数 p ≤ 5000）。p 为合数时直接给出因子 2^q − 1（q 为 p 的最小质因子）。
伪素数对底数 a 依次执行费马测试、欧拉测试（对比雅可比符号）、单基强测试，指出 n 是否为对应的伪素数；并用 Korselt 判据（无平方因子且 ∀p|n 有 p−1 | n−1）判定 Carmichael 数并展示验证过程。
欧拉函数计算 φ(n) 并展示由质因数分解出发的推导过程：φ(n) = n·∏(1 − 1/p)。
数论函数一次输出 φ、τ、σ、μ、λ、ω、Ω、rad，并判断平方无关/完全数/亲和数；「σₖ(n)」算因数 k 次幂和（k ≤ 100）；「φ 反问题」找出所有满足 φ(n) = m 的 n（m ≤ 10¹²），无解时说明该数是 nontotient。
阶乘勒让德勒让德公式 v_p(n!) = Σ⌊n/pⁱ⌋（展示每一项）；n! 完整素因子分解（n ≤ 10⁶）；任意 b 进制末尾零（b ≤ 10⁶）；n! 十进制位数（n ≤ 10¹²，大 n 用 Stirling 级数）；n! 精确值（n ≤ 5000）。
扩展欧几里得输入 a、b（可为负），输出 gcd、lcm，以及裴蜀恒等式 ax + by = gcd(a,b) 的一组解，并列出完整的辗转相除步骤表。
不定方程解 ax + by = c：有解 ⟺ gcd(a,b) | c，给出特解、通解 x = x₀ + (b/d)t，并可枚举全部非负整数解（自动求 t 的取值区间）。
线性同余解 ax ≡ b (mod m)。先算 d = gcd(a, m)：d 整除 b 才有解，此时在模 m 意义下恰有 d 个解，形如 x ≡ x₀ + k·(m/d)。「求 a⁻¹」直接给出 a 模 m 的乘法逆元（存在当且仅当 gcd(a, m) = 1）。
中国剩余定理逐行输入 x ≡ aᵢ (mod mᵢ)，可增删方程（2~8 个）。模数不必两两互素：工具会逐步合并并检查相容性，若某对方程矛盾会指出具体位置。输出最小非负解与通解 x ≡ x₀ (mod M)，M 为各模数的最小公倍数。
平方同余解 x² ≡ a (mod m)，m 任意（≤ 24 位）：自动分解 m，奇素数幂模用 Tonelli-Shanks + Hensel 逐位提升，模 2ᵏ 用特判公式（a ≡ 1 mod 8 时有 4 解），正确处理 a 含 p 因子（v_p 为奇数则无解）与 a ≡ 0 的情形，最后 CRT 组合。超过 256 个解时只报数量。
二项同余解 xᵏ ≡ a (mod p)，p 素数 ≤ 10¹²。取原根 g，用 BSGS 求 ind_g(a)，化为线性同余 k·t ≡ ind (mod p−1)：有解 ⟺ gcd(k, p−1) | ind，解数即 gcd(k, p−1)。
模幂运算计算 bᵉ mod m（快速幂）。e 为负时等价于求 (b⁻¹)^|e|，要求 b 与 m 互素，否则给出提示。
原根与阶「求乘法阶」：最小 k 使 aᵏ ≡ 1 (mod n)，须 gcd(a, n) = 1，阶必整除 φ(n)。「找最小原根」：对素数 p 求最小原根 g（对 p−1 的每个质因子 q 验证 g^((p−1)/q) ≢ 1）；勾选「列出全部」可枚举所有原根 gᵏ（k 与 p−1 互素，最多 500 个），原根总数为 φ(p−1)。
勒让德/雅可比(a/p) = 1 表示 a 是模 p 二次剩余，−1 为非剩余，0 表示 p | a，用欧拉判别法 a^((p−1)/2) 计算。雅可比符号 (a/n) 支持任意正奇数 n（含合数），按互反律递推，并给出中间步骤。「解 x² ≡ a」用 Tonelli-Shanks 算法给出两个平方根（若存在）。
离散对数BSGS 算法求最小 x ≥ 0 使 aˣ ≡ b (mod p)，复杂度 O(√p)，故限制 p ≤ 10¹²。无解时如实报告。
佩尔方程x² − D·y² = 1（D 非平方，≤ 9 位）：用 √D 的循环连分数求最小解，展示周期、验证等式、负佩尔（= −1）的可解性，以及由 (x₁+y₁√D)ᵏ 递推的前几组解。D 为平方数时明确拒绝。
连分数三种模式：p/q 展开为有限连分数；√n 展开为循环连分数并展示循环节（n ≤ 9 位）；连分数串（如 3;7,15,1,292）还原为最简分数。均列出渐进分数（即最佳逼近）与误差，√n 模式还指出与佩尔方程的联系。
组合计算C(n, k) 精确值（n ≤ 10⁴）、卡特兰数 Cₙ（n ≤ 5000）、分拆数 p(n)（n ≤ 5000，精确）；卢卡斯定理求 C(n,k) mod p：n、k 可达百位，p 为 ≤ 10⁶ 的素数，展示 p 进制分解过程。
进制转换2~36 进制互转，字符集 0-9a-z 不区分大小写，支持任意长度整数。

防呆与限制

  • 输入支持空格、逗号、下划线分隔与全角数字，自动清理后解析；非法输入会红框标出并在结果区给出具体原因。
  • 分解类运算（分解、φ、阶、原根）建议 ≤ 24 位；判素 ≤ 40 位；GCD、同余、模幂支持百位级大整数。
  • 模数必须为正整数；涉及逆元/阶/离散对数时会自动检查互素条件并说明。
  • 所有计算在主线程完成，超大输入可能耗时数秒，界面会给出「计算中」提示。
