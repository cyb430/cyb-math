# CYB Math 修复与测试报告

## 交付结论

本次交付包含两个可独立部署的版本：

- **V1 修复版**：在不改变十个数学工具核心功能和计算逻辑的前提下，完成统一导航、主站工具箱化、首次帮助精简、可信度说明、安全响应头和稳定性修复。
- **V2 UI 优化版**：以 V1 为功能基线，仅叠加视觉与交互样式优化；自动化校验确认十个工具的功能代码与 V1 一致。

云端基线来自 `https://cyb-math.pages.dev/` 及其十个已部署子站。抓取时主站源码 SHA-256 为：

`76bb537fbef958f26ab0b6b49804adf88885665f396fc0895c1e374bf40aa008`

## V1 已修复内容

### 1. 十站统一

十个子站均增加同一套常驻顶部栏，包含：

- CYB Math 品牌与当前工具名称；
- 十一站工具切换器；
- 返回总览；
- 主题、快速帮助、分享；
- 本地预览和线上部署两种链接解析方式。

所有帮助面板统一成“三步快速上手 + 可执行示例 + 完整说明入口 + 已知限制”，避免首次进入时被长文档阻塞。

### 2. 主站从链接目录升级为工具箱

主站已增加：

- 按名称、用途和关键词实时搜索；
- 七类工具筛选；
- 按任务推荐工具；
- 最近使用记录（仅保存在浏览器本地）；
- 桌面端双列、移动端单列布局；
- “本地计算、免费使用、无需登录”优势说明；
- 综合版与专业版的清晰分工；
- 更明确的产品定位：面向中学生与数学竞赛学习者的免费数学工具集。

### 3. 功能重叠说明

主站明确标注：

> 综合版适合快速计算；专业版适合深入绘图和分析。

函数绘图、几何等独立工具继续保留，作为更深入的专业入口；当前版本不声称不同工具间的数据自动互通，避免误导。

### 4. 可信度与限制说明

统一帮助面板补充了：

- 使用的计算引擎或算法类型；
- 输入范围与已知限制；
- 本轮测试口径；
- 问题反馈入口；
- “结果仅供学习辅助，重要结论请独立验证”的提示。

### 5. 安全修复

新增 Cloudflare Pages `_headers` 配置，覆盖：

- MIME 嗅探保护；
- 同源框架限制；
- Referrer Policy；
- 摄像头、麦克风、定位、支付、USB 权限禁用；
- HSTS；
- COOP/CORP；
- CSP：禁止对象嵌入、限制连接来源、限制表单与基址等。

为兼容现有单文件工具内嵌的 Pyodide/Emscripten/Algebrite 运行时，CSP 暂时保留了 `unsafe-inline` 和 `unsafe-eval`。这是已记录的剩余风险；若进一步收紧，需要把内联脚本、样式和大型运行时拆分为独立静态资源，并引入 nonce/hash 构建流程，这会超过本次“不改变功能代码”的约束。Cloudflare Pages 的自定义响应头规则见[官方文档](https://developers.cloudflare.com/pages/configuration/headers/)。

输入注入测试覆盖主站搜索、方程解析和数论输入。恶意 HTML 字符串均未被当作页面元素执行；抽查的动态输出路径使用转义、`textContent` 或受限数学渲染器。

## V2 UI 优化内容

V2 在 V1 的 HTML 结构和功能脚本基础上，仅增加一层视觉 CSS：

- 统一深海军蓝与青色的品牌色；
- 加强顶部导航的产品识别度；
- 将搜索区设计成更明显的工具入口；
- 提升正文、网址和辅助文字的字号与对比度；
- 优化卡片层级、间距、悬停反馈和键盘焦点；
- 调整移动端排版与触控间距；
- 尊重 `prefers-reduced-motion`，减少动画敏感用户的不适。

自动化不变量校验确认：V2 与 V1 的十个工具功能源码一致，差异限定在新增视觉样式。

## 已知限制与后续建议

- 这是高覆盖率的本地静态、浏览器与核心流程测试，不等同于第三方形式化安全审计或所有数学分支的穷举证明。
- 现有大型单文件中包含第三方运行时；建议后续锁定依赖清单、公开版本号和许可证，并建立可复现构建。
- 建议为代数、方程、平方同余、离散对数等模块补充公开的参数化测试集，并在页面上展示真实累计用例数；本次没有用无法审计的虚构数字替代。
- 建议建立统一问题追踪地址；当前统一帮助保留反馈入口，但正式发布前应替换为项目真实的 GitHub Issues 或长期维护邮箱。
- 若未来需要跨工具传递表达式或图形数据，应先设计明确的数据格式和隐私边界，再增加“发送到专业版”等能力。

## 部署前检查

每个 Cloudflare Pages 项目应将对应工具 HTML 作为该项目根目录的 `index.html`，并同时复制 `_headers`。部署后逐站确认响应头已经生效，并重新运行冒烟测试。具体映射见《CYB Math 部署说明》。
