# CYB Math V3 主站改进说明

## 视觉调整

- 删除重复的说明卡片和偏目录式的纵向堆叠；
- 首屏整合标题、搜索、分类和核心优势；
- 使用纸白背景、墨色正文和蓝/青/橙/紫/玫红五种低饱和工具色；
- 颜色只服务于工具识别、搜索反馈和交互状态；
- 常用入口改为紧凑标签，十个工具保持桌面双列、移动单列；
- 深色主题、键盘焦点和减少动画模式同步适配。

## 模糊搜索

搜索会综合工具名称、用途、分类、关键词和部分常用拼音：

- 完整词和前缀优先；
- 支持包含匹配；
- 支持字符顺序近似，例如“函图”；
- 使用编辑距离容忍轻微错别字，例如“质树”仍会推荐数论工具；
- 输入时最多显示五条自动推荐；
- 空搜索聚焦时显示最近使用或常用工具；
- 支持方向键选择、回车进入和 Esc 关闭。

动态推荐内容全部通过 DOM 文本节点生成，不使用 `innerHTML` 写入用户内容。

## 验证

- 26/26 项主站结构、脚本、搜索算法与安全检查通过；
- “质树”“zhishu”“函图”模糊匹配用例通过；
- 无关词“咖啡”不会产生错误推荐；
- 十个子站文件哈希与 V2 精修版一致；
- `_headers` 安全配置保持不变。

当前交付尚未覆盖线上生产主站。
