# CYB Math 用户体验审查与改进报告

## 范围与原则

以普通学习者“找到工具 → 输入 → 计算 → 看懂结果 → 修正错误 → 保存或分享 → 下次继续”为主线，同时考虑手机触摸、键盘操作、弱网/离线和长时间编辑。重点是少打断、少丢输入、结果可带走，而不是增加装饰。

使用真实 Chrome 检查桌面 1366×900、手机 390×844；使用 Electron 检查离线桌面页面和打包程序。Android 另以 1080×2400 模拟器检查原生顶栏、输入法、特殊键和系统文件选择器。HarmonyOS NEXT 检查 ArkTS 编译与共享引擎一致性；没有设备运行验证，不能混称真机体验。

## 总体结论

原产品数学工具丰富，主要障碍不是缺少首页介绍，而是进入工具被帮助遮挡、导航与内部操作不一致、尚未计算的输入不能可靠继续、结果不容易导出，以及手机导出失败缺少反馈。新增功能选择与这些实际任务直接相关的最小二乘拟合、收藏和数据导出。

本报告中确定的改进均已实施。对原本已具备的撤销、视野验证、图像导出和分享功能，重点做工作流验证并保留原实现，没有为增加功能数重复建设。

## 新增数学能力

线性代数新增“最小二乘”：

- 直线拟合 `y = ax + b`：直接粘贴两列数据，显示系数、R²、RMSE、残差及散点/拟合线。
- 线性方程组近似解：每行输入系数和右端值，处理超定、欠定及秩亏系统；给出最小范数解、秩与数值风险提示。
- 输入检查、示例、三语、草稿与页签恢复、分享、文本复制和残差 CSV 一并完成。修改数据后旧结果不可直接导出。
- 核心使用 `ml-matrix` 的 SVD，不自写分解算法；依赖和完整许可内嵌 HTML，离线使用无需访问外部服务。
- 数值缩放改善大/小数量级表现；完全相同的横坐标不伪造唯一拟合直线。仍受 JavaScript 双精度和问题条件数限制，不宣称任意规模/病态问题都可靠。

## 已知限制与后续建议

- Android 已在模拟器完成系统保存和输入测试，但仍需实体设备覆盖厂商输入法、文件选择器取消/再次保存、后台切回、低存储空间与系统深色模式。
- Windows 安装版生成成功，实际运行验证使用隔离的便携版，未覆盖已有正式安装或完整运行安装向导；没有商业代码签名证书，首次下载可能显示系统信誉提示。
- HarmonyOS HAP 尚无开发者签名与实体设备测试，只能作为工程构建结果；正式安装、商店发布和设备性能不能据此宣称完成。
- 数学引擎保留既有边界：极端病态矩阵、复杂表达式和大量动态图形仍需专门数值/性能验证。结果必须结合条件数和警告理解。
- 后续可研究本地学习项目统一保存、多结果对比、单位/有效数字约定、更多回归题；这类新模块需另定数据格式和验收标准，不冒充本次已完成。
- 每小时自动续跑的原生应用接口返回不可用，未成功建立轮询。进度另存 `UX_PROGRESS.md`，不能保证用量中断时自动唤醒。
